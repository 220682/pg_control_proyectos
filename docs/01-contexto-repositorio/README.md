# Contexto del repositorio

## Qué vive acá

Todo lo específico de `pg_control_proyectos`: propósito y alcance del repo, arquitectura y fuentes de verdad, entorno Git/worktrees real, cómo se prueba, y cuándo aplica el sistema de diseño.

## Qué no vive acá

El estándar reusable de agentes (eso vive en [`../00-estandar-agentes/`](../00-estandar-agentes/README.md)) ni las reglas de negocio (eso vive en [`../04-flujos-de-negocio/`](../04-flujos-de-negocio/README.md)).
