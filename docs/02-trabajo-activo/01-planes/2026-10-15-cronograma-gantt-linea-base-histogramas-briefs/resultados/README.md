# Resultados de tanda

Cada Worker deja aquí su resumen de cierre como `<tanda>.md` (por ejemplo `C1.md`), con la plantilla `docs/00-estandar-agentes/06-plantillas/12-resumen-de-cierre-de-tanda.md`: ítems con estado y evidencia (máximo una captura por ítem), archivos tocados, validaciones, hallazgos en los cinco grupos, preguntas y traspaso. Vacía hasta que empiece la ejecución.
