# Diseño y referencias

## Qué vive acá

El sistema de diseño (`design.md`: layout, tokens, componentes, tablas, accesibilidad) y los mockups visuales de referencia en `mockups/` (migrados desde `docs/visual-companion/`).

`design.md` es lectura **obligatoria** antes de crear o modificar cualquier pantalla de `py_control_proyectos_web`.

## Nomenclatura oficial (2026-08-19)

| Uso | Texto |
|-----|-------|
| Módulo / pantalla | **Requerimiento de servicios** |
| Botón, chip, acción | **Crear requerimiento de servicios** |
| Modal consulta | **Ver partidas** |

## Qué no vive acá

Evidencia de pruebas de un plan (eso vive en `../02-trabajo-activo/03-evidencia/`).
