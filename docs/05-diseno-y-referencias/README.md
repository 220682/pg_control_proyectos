# Diseño y referencias

## Qué vive acá

El sistema de diseño (`design.md`: layout, tokens, componentes, tablas, accesibilidad) y los mockups visuales de referencia en `mockups/`.

`design.md` es lectura **obligatoria** antes de cualquier cambio de interfaz.

## Qué no vive acá

Evidencia de pruebas de un plan (eso vive en `../02-trabajo-activo/03-evidencia/`).
